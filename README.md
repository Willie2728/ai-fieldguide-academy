# AI FieldGuide Academy

Launch-ready MVP for a practical AI subscription course. It includes a multi-page website, learner dashboard, ten-module curriculum, twenty reusable prompts, ten purchase reasons, four pricing levels, lead funnels, four 45+ second workplace campaign videos, seven original lesson visuals, five selectable logo/tagline directions, and Willie as a persistent AI Wisdom Guide.

## Start locally

1. Double-click `start-site.cmd`.
2. Open `http://localhost:8787`.
3. The website works without an API key. Live Willie answers require the secure server setup in `SETUP.md`.

Do not open `index.html` using a `file:///` address. The secure guide, leads, and checkout connectors require the local server.

## What is implemented

- Website: home, course, teams, income, business plan, brand lab, privacy, and terms pages.
- App: browser-persisted lesson progress for the MVP.
- Willie: persistent panel, course-aware system instructions, optional spoken answers, page context, rate limiting, and server-side provider adapters.
- AI providers: OpenAI by default; Anthropic and local Ollama adapters are included.
- Funnels: three lead magnets, consent capture, local lead storage, and optional webhook forwarding.
- Checkout: environment-configured payment-link handoff for each tier.
- Media: seven SVG lesson visuals and four silent 45+ second MP4 concept cuts assembled from licensed Pexels workplace footage.
- Deployment: Render configuration and a no-dependency Node server.

## Important launch gaps

This is a product MVP, not a completed subscription business. Before taking public payments, add authenticated learner accounts, a production database, entitlement checks, billing webhooks, transactional email, final course recordings, support operations, analytics, monitoring, backups, an accessibility audit, and lawyer-reviewed policies. Validate the product with paid learners before relying on projected MRR.

The name and logos are working concepts. Complete trademark and domain review before commercial launch.
